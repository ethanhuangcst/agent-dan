# Production workflows

Executable workflow definitions (YAML) for the Work Agent **workflow engine**, MCP `workflow_list` / `workflow_run`, and the web agent core.

- **Draft** markdown: `agent/define-workflows/`
- **Schema:** add `schema.workflow.json` here for CI validation
- **Architecture:** [`agent/architecture.md`](../../agent/architecture.md)

Do not run workflows from draft folders; promote to this directory first.
