# Step 3 — Revision loop (until confirmed)

While the user has **not** confirmed the research with **yes**:

1. Incorporate their feedback and any new messages in this thread as user-provided evidence.
2. Follow **research-ops** again (lighter or deeper path as appropriate — do not skip fresh verification when the feedback changes the question).
3. Return to **summarize-and-confirm** (step 2): updated summary and the same confirmation question.

Repeat until the user confirms.

Only after explicit confirmation, proceed to the **store** step (knowledge-ops + MCP `knowledge_write`).
